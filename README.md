# RUSHING THROUGH · 紧张地穿梭

一个像素游戏风的展示小站，收着三个可以亲手玩的小世界，和一条把它们串起来的线。

## 在线访问

<https://qiaojinghan910.github.io/rushing-through/>

## 本地运行

```bash
python3 server.py
# 打开 http://localhost:8123
```

## 结构

- `index.html` — 展示页本体（纯静态，单文件）
- `server.py` — 本地预览用的小服务器（Python 标准库，无依赖）

四个作品的在线版分别由各作者维护：

1. 光影追猎（CHASE）— <https://wzqwzq519.github.io/shadertoy-1d-radial-lightmap/>（原 shader 作者 Flyguy · CC BY-NC-SA 3.0）
2. 池塘一梦（DISTURBANCE）— <https://sonwnooo.github.io/pond/>
3. 转眼（PASSAGE）— <https://qiaojinghan910.github.io/lifebook/>
4. 一线三梦（THE THREAD）— <https://sonwnooo.github.io/lifebook/>
